# Security Policy

## Supported versions

Security updates are currently provided for the latest published release.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** option from the repository's **Security** tab. If that option is unavailable, contact the maintainer privately through [lorenzoperrone.it](https://www.lorenzoperrone.it/) and do not include exploit details in a public message.

Include a clear description, reproduction steps, affected versions, impact, and any known mitigation. Remove credentials, personal data, and unrelated sensitive information from the report.

You should receive an initial response within seven days. Please allow time for investigation and a coordinated fix before public disclosure.
